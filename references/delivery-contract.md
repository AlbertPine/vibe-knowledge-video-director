# 交付与验收

## 默认成片规格

- 分辨率：1920 × 1080。
- 帧率：30 fps。
- 时长：2 至 3 分钟；故事需要更短时以节奏为先。
- 视频：H.264、yuv420p、BT.709。
- 音频：可使用音乐和音效；默认没有语音旁白。
- 文字：简体中文，检查错字、标点、年份、专有名词和断句。

用户给出其他平台规格时，以用户要求为准。

## 必须执行的检查

1. 实际渲染完整 MP4，不能只交预览或截图。
2. 使用媒体探测工具确认时长、分辨率、帧率、编码、色彩和音轨。
3. 检查开头、10%、25%、50%、75%、95% 和最后一帧。
4. 对文字密集、快速运动、转场和核心机制场景增加抽帧检查。
5. 确认没有黑帧、残留元素、越界、遮挡、字体缺字、错别字或半句跨幕。
6. 确认核心机制至少有一次完整的输入、处理和结果动画。
7. 观看全片节奏；连续 4 秒没有信息、动作或情绪变化时，说明停滞，需要压缩或增加因果动作。

## 推荐目录

```text
项目名/
├─ research/       # 来源、断言账本、参考片分析
├─ storyboard/     # 故事结构和场景计划
├─ src/            # 可编辑工程
├─ assets/         # 本地冻结素材
├─ renders/        # 试渲染与最终成片
└─ DELIVERY_QA.md  # 媒体参数和检查记录
```

系列成片另存到统一合集：

```text
系列名/
├─ README.md
└─ 成片/
   ├─ 01-片名-主题.mp4
   └─ 02-片名-主题.mp4
```

## 完成标准

只有以下条件同时满足才算完成：事实有边界、故事能独立看懂、动画承担解释、文字语义完整、成片已渲染、代表帧已检查、工程可继续修改。
